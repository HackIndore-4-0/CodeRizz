Challenge 2: Real-Time Geospatial Density Clustering To detect and locate disasters 
efficiently, implement a spatial clustering algorithm (e.g., DBSCAN) that processes 
incoming, geo-tagged social media data to dynamically identify high-density impact 
zones. The algorithm must group overlapping reports within a specific radius, filter out 
isolated data points as noise, and automatically generate a priority heat map to bridge 
the gap between fragmented disaster information and real-time response. 
Expected Outcome: 
● A backend implementation of a spatial clustering algorithm optimized for 
real-time coordinate streams derived from social media data extraction. 
● A live frontend map rendering that dynamically draws and updates heat maps 
over the highest-priority disaster clusters. 
● A quantified output of the cluster density to help prioritize where emergency 
responders should be deployed first.
